# HappyEat 设计规格（可观察项清单）

出处：与用户逐条确认的设计共识（grilling 会话 Q1–Q26，2026-10-16），已固化于 AGENTS.md。
**v2 修订（2026-10-16 真机试玩反馈，AGENTS.md 玩法规格 v2）**：新增主菜单、玩家跳跃、BGM/音效实装、背景阶段切换与可选、物品类别光环与配色对比、开局教学与帮助页；受影响条目已就地更新并标注 (v2)。
本项目为安卓原生游戏，**无源视频**；[D] 行的出处标注为共识确认轮次（Q 编号）而非视频切片。

## 静态 / 结构项 [S]

- [S1] (v2) 启动进入主菜单（开始游戏/排行榜/设置/帮助）；点开始游戏后进入竖屏全屏 SurfaceView 游戏画面 + 顶部 HUD（左：分数/生命/送命进度；右：暂停按钮、齿轮按钮）。(Q9 + 真机反馈#4)
- [S2] 应用标识：applicationId=com.happyeat.game，显示名 HappyEat；minSdk 24，竖屏锁定。(Q3/Q10)
- [S3] 玩家精灵位于屏幕底部水平线上，可左右拖动；尺寸≈屏宽 11%。(Q4)
- [S4] 掉落物精灵共 8 种：豆子、肉、馅饼（食物）；石头、炸弹、刀（危险物）；汽车、坦克（载具）；尺寸≈屏宽 7.5%。(Q2/Q22)
- [S5] 猛兽精灵 3 种：虎、狮、狼，出现在与玩家同一水平线；尺寸≈屏宽 12%。(Q22)
- [S6] (v2) 背景：白天/黄昏/夜晚三张竖屏图（AI 生成日景+调色变体），游戏进行中随阶段自动切换，设置可固定；无视差滚动。(Q11/Q24 + 真机反馈#2)
- [S7] 所有数值集中在 `config/GameConfig.kt`：分值、频率、速度、命、无敌时长、判定比例、难度封顶等，逻辑代码无魔法数字。(Q8)
- [S8] UI 文案全部走 strings.xml：`values/`（英文默认）+ `values-zh/`（中文）。(Q20)
- [S9] (v2) 素材为 AI 生成的统一卡通风格透明底 PNG，置于 `app/src/main/assets/sprites/`；掉落物渲染带类别光环（绿=食物/黄=载具/红=危险），危险物深暗、食物亮暖，高对比可辨；缺失时回退为彩色圆形占位、不崩溃。(Q11 + 真机反馈#6)

## 动态 / 行为项 [D]

- [D1] 拖动：手指横移多少玩家横移多少（相对拖动），边界内 clamp。(Q4)
- [D2] 掉落生成：基础每 0.9 秒 1 个，分布=豆 50%/肉 10%/馅饼 8%/载具 4%/危险物 28%（石头/炸弹/刀各 9.33%）；下落基础速度 0.28×屏高/秒 ×难度系数。(Q22)
- [D3] 接住食物得分：豆+1、肉+5、馅饼+10，得分即时反映在 HUD。(Q18)
- [D4] (v2) 生命：3 条起步；未骑乘时被危险物或猛兽碰到 → 命-1，随后 2 秒无敌（精灵闪烁）；快速点按可跳跃躲过地面猛兽；命=0 → Game Over。(Q6/Q14 + 真机反馈#5)
- [D5] 送命：每得 200 分 +1 命，上限 30 条。(Q15)
- [D6] 载具：接住车/坦克进入骑乘，持续 10 秒或累计 3 次撞击后报废（先到为准）；期间照常接食物；再接载具只刷新时长、撞击数不重置；报废恢复普通态。(Q7/Q16)
- [D7] 骑乘中碰撞：危险物被撞毁+3 分、猛兽被撞毁+10 分，均计入撞击次数；玩家不掉命。(Q7/Q16)
- [D8] 猛兽：从屏幕左/右随机一侧生成，单向直线穿越、不折返，出对侧即消失；基础速度 0.35×屏宽/秒 ×难度；移动中随机起跳（概率 0.8/秒），跳跃只改纵向位置不改方向；基础每 9 秒 1 只，同屏最多 3 只。(Q22)
- [D9] 难度曲线：难度系数 = 1 + 1.5×min(1, 游戏时间/5 分钟)，即 5 分钟后封顶 2.5 倍。(Q17)
- [D10] 碰撞判定框 = 精灵显示尺寸 × 0.75（所有实体），擦边不死。(Q21)
- [D11] 暂停：点暂停按钮或齿轮 → 游戏暂停；暂停面板含"继续"与"设置"。(Q9/Q26)
- [D12] 设置（语言）：弹窗仅一项"跟随系统/English/中文"，选择经 AppCompatDelegate.setApplicationLocales 即时生效并持久化（重启保持）；默认跟随系统。(Q20/Q26)
- [D13] 用户名：首次启动弹一次输入框（去首尾空格 2–20 字符，允许中文/emoji），存 SharedPreferences，之后不再弹。(Q25)
- [D14] 本机排行榜：死亡自动写入 Room（用户名+分数+日期时间戳）；Game Over 面板"排行榜"按钮弹窗显示本机前 50 条（按分降序），并标出当前用户最佳纪录；无后端、断网不影响。(Q25)
- [D15] Game Over：半透明面板显示 Game Over、本局分、历史最高分（SharedPreferences）、"排行榜"与"重新开始"按钮；重开即重置全部状态。(Q9)
- [D16] (v2) 音频：BGM 循环随游戏进行播放（暂停/菜单/结束停）+ 合成音效（吃/受伤/骑乘/撞毁/跳跃/按钮/结束）经 SoundPool 播放。(Q10 + 真机反馈#1)
