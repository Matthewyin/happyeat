## 完整说明 / Full description
zh-CN:
```
HappyEat 是一款轻松上手的接物休闲游戏——接住美味，躲开危险！

🫘 简单直觉的操作
在底部移动区左右滑动，接住从天而降的豆子、肉和馅饼；按下跳跃键躲避危险。支持双指同时操作，设置可交换左右位置！

💣 危险从天而降
石头、炸弹、飞刀随时砸下来——看清物品及时躲开！碰到就掉命。

🐯 猛兽贴地突袭
老虎、狮子、狼贴着地面冲过来，还会突然起跳——算好时机跳过去！

🚜 接收坦克，移动射击
NPC 从侧面送来坦克，停稳后只有 3 秒上车机会！驾驶时跳跃键变为射击键，3 发炮弹可击败猛兽；持续 15 秒或承受 3 次撞击后报废，以先到为准。

🌙 越玩越刺激
难度逐步升级，背景从白天渐变到黄昏和夜晚；每 200 分送一条命，最高 30 条命！

🏆 本机排行榜
记录你的每一局成绩，挑战自己的最高分。

• 完全离线可玩，不收集任何个人数据
• 中英双语界面
• ACE-Step 生成的器乐游戏配乐
• 无广告
```
